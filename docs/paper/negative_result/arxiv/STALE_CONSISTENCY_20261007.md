# Status of the generated LaTeX (updated 2026-10-07)

`main.tex`, `supplement.tex`, `submission/`, `twocolumn/`, the tables and `main.bbl` in this directory were regenerated by `scripts/build_arxiv_latex.py` from the consistent `MANUSCRIPT_DRAFT_v1.md` on the branch that folds the E1 Track A correction (PR #109), the rebuild (PR #110) and the consistency cleanup (PR #111). Release packages are tagged REV5 in `/mnt/project-files/arxiv/`; REV1 and earlier packages are quarantined under `SUPERSEDED_*` folders there and must not be uploaded.

The source of truth for the references is the Markdown `References` section; `references.bib` is generated from it and checked by `build_arxiv_latex.py`. Any later edit of a section source requires rerunning `scripts/assemble_manuscript.py`, `scripts/build_arxiv_latex.py` and the packaging scripts.
